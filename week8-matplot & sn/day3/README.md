# Day 3 - Seaborn Visualization

## Overview
This lesson introduces Seaborn, a Python library designed for statistical and attractive data visualization. It is especially useful for exploring relationships, distributions, and patterns in datasets.

## Topics Covered
- Seaborn plotting basics
- Distribution plots
- Categorical data visualization
- Styling and theme improvements
- Creating more polished charts than basic Matplotlib plots

## Practice Files
- `seaborn.ipynb`
- `seaborn2.ipynb`

## Learning Objectives
By the end of this lesson, you should be able to:
- create attractive plots using Seaborn
- visualize relationships between variables
- compare groups with cleaner statistical plots
- produce charts suitable for analysis and presentations

## Tools Used
- Python
- Seaborn
- Matplotlib
- Pandas
- Jupyter Notebook

## Typical Visuals
- boxplots
- bar plots
- distribution plots
- comparison charts
