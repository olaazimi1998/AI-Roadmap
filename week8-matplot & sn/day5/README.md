# Day 5 - CSV and Excel Data EDA

## Overview
This session applies data visualization and analysis to a real CSV-based dataset. The focus is on exploring sales or product data, understanding distributions, and identifying trends important for business analysis.

## Topics Covered
- Loading CSV files with Pandas
- Exploring dataset structure and columns
- Checking missing or inconsistent values
- Descriptive statistics
- Visualizing sales or product trends
- Basic exploratory data analysis workflow

## Practice Files
- `working for excel and csv for eda.ipynb`
- `sales.csv`

## Learning Objectives
By the end of this lesson, you should be able to:
- read and inspect CSV data in Python
- summarize dataset statistics
- identify patterns in sales or product data
- build simple EDA charts to support business insights

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Typical Analysis Flow
1. Load the dataset
2. Inspect columns and data types
3. Clean and prepare the data
4. Summarize key metrics
5. Visualize trends and relationships
6. Report findings
