# Employee Data Analytics System

## Description

A SQL database project for managing employees,
departments, projects, and employee assignments.

## Tables

- departments
- employees
- projects
- employee_projects

## SQL Concepts

- DDL
- DML
- Primary Keys
- Foreign Keys
- JOIN
- GROUP BY
- HAVING
- Subqueries
- CTE
- Window Functions
- Indexes

## Complex Queries

1. Employees with departments
2. Average salary by department
3. Departments with high average salary
4. Highest-paid employee
5. Employees above average salary
6. Salary ranking
7. Department salary ranking
8. Highest-paid employee per department
9. Employees and projects
10. Project salary analysis
