# Day 1 - Probability

## Overview
This lesson introduces the basics of probability and how uncertainty is measured in data and machine learning.

## Topics Covered
- Random events
- Sample spaces
- Basic probability
- Independent and dependent events
- Probability rules

## Learning Objectives
By the end of this lesson, you should be able to:
- explain what probability means
- calculate simple probabilities
- understand how events and outcomes relate to each other
- apply probability rules to basic examples

## Tools Used
- Python
- Jupyter Notebook
- Basic math concepts

## Practice
Use the notebook or script in this folder to solve probability exercises and understand how probability works in real examples.
