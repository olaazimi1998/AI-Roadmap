# Week 10 - Regression Project

This project demonstrates Linear Regression and Logistic Regression.

The models are implemented in two ways:

1. From scratch using NumPy
2. Using Scikit-learn

---

## Project Goals

The goals of this project are:

- Understand Linear Regression
- Understand Logistic Regression
- Understand Gradient Descent
- Understand the Sigmoid function
- Build models from scratch
- Use Scikit-learn models
- Compare the two approaches
