# Day 2 - Customizing and Comparing Visualizations

## Overview
This session focuses on improving chart quality and comparing multiple data series visually. Students learn how to style charts for more professional presentation.

## Topics Covered
- Customizing colors and line styles
- Adding legends and labels
- Plotting multiple products or categories together
- Comparing trends across groups
- Improving chart aesthetics for presentation

## Practice File
- `customizing-comparing.ipynb`

## Learning Objectives
By the end of this lesson, you should be able to:
- create multi-series comparison charts
- use legends to differentiate categories
- customize plot appearance for clarity
- analyze and explain differences between datasets visually

## Tools Used
- Python
- Matplotlib
- Jupyter Notebook

## Example Concepts
- Monthly sales comparison
- Multi-line plots
- Visual storytelling with charts
