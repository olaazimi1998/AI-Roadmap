# Day 1 - Data Visualization Fundamentals

## Overview
This session introduces the basics of data visualization using Python and Matplotlib. The goal is to learn how to turn raw data into clear graphs that communicate patterns and insights.

## Topics Covered
- Creating simple line charts
- Plotting numeric data with Matplotlib
- Customizing axes, titles, and labels
- Reading trends across time series data
- Building clean, readable visualizations

## Practice File
- `data-vasualization.ipynb`

## Learning Objectives
By the end of this lesson, you should be able to:
- create basic charts from Python lists or data arrays
- interpret simple trends in visual data
- improve chart readability using labels and titles
- present data clearly for analysis and reporting

## Tools Used
- Python
- Matplotlib
- Jupyter Notebook

## Suggested Review Questions
- What does the chart communicate about the dataset?
- Which type of chart is best for the data being shown?
- How can styling improve clarity?
