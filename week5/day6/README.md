# Day 6 - Hypothesis Testing Review

## Overview
This final day reviews the statistical testing process and reinforces the main ideas needed to evaluate data claims carefully.

## Topics Covered
- Review of hypothesis testing
- Statistical significance
- Decision-making from data
- Interpretation of results
- Confidence in conclusions

## Learning Objectives
By the end of this lesson, you should be able to:
- summarize the core ideas of hypothesis testing
- explain why evidence matters in analysis
- connect tests to real-world decisions
- revise and strengthen your understanding of statistics

## Tools Used
- Python
- Statistics concepts
- Jupyter Notebook

## Practice
Review the examples in this folder and make sure you understand how to evaluate evidence before drawing conclusions.
