# Day 5 - Putting Statistics Together

## Overview
This lesson combines the major statistical ideas from earlier in the week into a broader workflow for data analysis.

## Topics Covered
- Descriptive statistics
- Distribution analysis
- Correlation
- Hypothesis thinking
- Full data interpretation

## Learning Objectives
By the end of this lesson, you should be able to:
- connect different statistical techniques together
- analyze a dataset more completely
- explain patterns using multiple statistical views
- move from raw data to meaningful conclusions

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Practice
Apply the concepts learned this week to the example dataset and summarize the findings clearly.
