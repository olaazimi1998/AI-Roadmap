# Day 4 - Heatmaps and Correlation Analysis

## Overview
This lesson focuses on understanding relationships between numerical variables using correlation and heatmaps. It is a key part of Exploratory Data Analysis (EDA).

## Topics Covered
- Correlation coefficient calculation
- Heatmap creation
- Identifying strong and weak relationships
- Interpreting data patterns visually
- Using correlation as a first step in feature analysis

## Practice File
- `heatmap & correlation.ipynb`

## Learning Objectives
By the end of this lesson, you should be able to:
- calculate correlations between variables
- interpret positive and negative relationships
- build heatmaps to visualize correlation matrices
- use visual analysis to guide deeper data exploration

## Tools Used
- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

## Important Concept
A heatmap helps summarize many relationships at once, making it easier to spot patterns in data.
