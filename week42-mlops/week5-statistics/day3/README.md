# Day 3 - Correlation

## Overview
This lesson introduces correlation, which measures the relationship between two variables.

## Topics Covered
- Correlation coefficient
- Positive and negative correlation
- Strength of relationships
- Data trends

## Learning Objectives
By the end of this lesson, you should be able to:
- explain what correlation means
- identify positive and negative relationships
- interpret correlation strength
- use correlation to explore data patterns

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Practice
Use the script in this folder to examine how pairs of variables move together and interpret the results.
