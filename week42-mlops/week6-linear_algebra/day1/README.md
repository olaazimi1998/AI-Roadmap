# Day 1 - Linear Algebra

## Overview
This lesson introduces the basics of linear algebra, including vectors and matrices, which are essential for machine learning and data science.

## Topics Covered
- Vectors
- Matrices
- Matrix dimensions
- Basic linear algebra notation
- Working with arrays in Python

## Learning Objectives
By the end of this lesson, you should be able to:
- explain what a vector and matrix are
- identify matrix shape and dimensions
- perform basic operations with arrays
- understand why linear algebra matters in AI

## Tools Used
- Python
- NumPy

## Practice
Use the exercise in this folder to build confidence with arrays and matrix structure.
