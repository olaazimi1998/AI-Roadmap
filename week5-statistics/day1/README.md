# Day 1 - Statistics Basics

## Overview
This lesson introduces the key ideas behind statistics, including how data is summarized and interpreted.

## Topics Covered
- Mean
- Median
- Mode
- Variance
- Standard deviation
- Descriptive statistics

## Learning Objectives
By the end of this lesson, you should be able to:
- explain the main statistical measures
- calculate basic statistics from data
- interpret central tendency and spread
- use statistics to understand data better

## Tools Used
- Python
- Basic math
- Jupyter Notebook

## Practice
Use the script in this folder to compute and interpret summary statistics from sample data.
