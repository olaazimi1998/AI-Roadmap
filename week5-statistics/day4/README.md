# Day 4 - Hypothesis Testing

## Overview
This lesson introduces hypothesis testing, a process used to evaluate assumptions and determine whether differences observed in data are statistically significant.

## Topics Covered
- Null hypothesis
- Alternative hypothesis
- Significance
- Testing assumptions
- Decision-making based on data

## Learning Objectives
By the end of this lesson, you should be able to:
- explain the idea of a hypothesis test
- distinguish between null and alternative hypotheses
- understand how we judge statistical significance
- interpret test results in a data context

## Tools Used
- Python
- Statistics concepts
- Jupyter Notebook

## Practice
Use the exercises in this folder to understand how evidence is evaluated before drawing conclusions from data.
