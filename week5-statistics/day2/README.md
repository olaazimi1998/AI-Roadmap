# Day 2 - Distribution

## Overview
This lesson focuses on how data is distributed and how distribution affects analysis and interpretation.

## Topics Covered
- Distribution of data
- Frequency
- Spread of values
- Data patterns
- Visual interpretation

## Learning Objectives
By the end of this lesson, you should be able to:
- describe how data is spread
- identify patterns in distributions
- explain why distribution matters in analysis
- interpret simple visual summaries of data

## Tools Used
- Python
- Matplotlib
- Jupyter Notebook

## Practice
Use the file in this folder to explore how values are spread and how frequency changes across ranges.
