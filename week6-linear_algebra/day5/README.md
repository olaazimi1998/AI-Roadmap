# Day 5 - Matrix Inverse

## Overview
This lesson introduces matrix inverse, a powerful concept used to solve systems of equations and understand linear transformations.

## Topics Covered
- Inverse matrix
- Identity matrix
- Solving linear systems
- Why inverses matter in algebra and ML

## Learning Objectives
By the end of this lesson, you should be able to:
- explain what an inverse matrix is
- identify when an inverse exists
- connect inverse matrices to solving equations
- understand why matrix inversion matters in data science

## Tools Used
- Python
- NumPy

## Practice
Work through the matrix inverse examples in this folder and focus on how the inverse relates to the identity matrix.
