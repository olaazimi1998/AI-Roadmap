# Day 2 - Matrix Multiplication

## Overview
This lesson focuses on multiplying matrices and understanding how row-column operations create a new matrix.

## Topics Covered
- Matrix dimensions
- Row-column multiplication
- Matrix product rules
- Practical examples

## Learning Objectives
By the end of this lesson, you should be able to:
- multiply matrices correctly
- check whether multiplication is valid
- understand how dimensions affect the result
- interpret the output of a matrix multiplication

## Tools Used
- Python
- NumPy

## Practice
Follow the matrix multiplication exercise in this folder and verify the results step by step.
