# Day 3 - Dot Product

## Overview
This lesson introduces the dot product, one of the most important operations in linear algebra and machine learning.

## Topics Covered
- Dot product definition
- Vector operations
- Similarity measures
- Practical examples

## Learning Objectives
By the end of this lesson, you should be able to:
- compute the dot product of two vectors
- explain what the result represents
- connect dot products to similarity and projection
- use dot products in basic ML reasoning

## Tools Used
- Python
- NumPy

## Practice
Solve the dot-product exercises in this folder and focus on the relationship between vector components and the final scalar output.
