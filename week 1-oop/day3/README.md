# Week 1 Day 3 — Inheritance, Classes, and Simple Account Logic

This folder is intended to contain Python examples for inheritance, object composition, and basic account behavior.

## What this day teaches

- How one class can inherit behavior from another (`Dog` inherits from `Animal`).
- How to extend a base class with specialized subclasses (`Bowing` extends `Airplane`).
- How constructors pass parameters to parent classes using `super()`.
- How encapsulation and properties can protect account balances.
- How to override methods and reuse parent logic.

## Example classes

- `Animal` and `Dog` — basic inheritance and shared behavior.
- `Airplane` and `Bowing` — vehicle class hierarchy with engine logic and passenger data.
- `BankAccount` and `Account1` — account balance management with validation and deposits.

## How to run

From this folder, run the main script once the source files are placed here:

```bash
python main.py
```

If the example files are not present in this folder, copy `main.py` and `models.py` from the source version into `week 1/day3/` first.

## Notes

This day is designed to reinforce inheritance by showing how child classes reuse and extend parent class implementations while keeping code organized.
