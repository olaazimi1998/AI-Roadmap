# Week 1 Day 1 — Intro to Classes and Objects

This folder contains Python examples that introduce fundamental object-oriented concepts, including simple classes, methods, object creation, and basic data encapsulation.

## Files

- `main.py` — runs multiple examples of class usage and object behavior.
- `models.py` — defines calculator, model, house, car, and teacher classes used in the examples.

## What this day teaches

- How to define and instantiate classes.
- How constructors (`__init__`) assign object data.
- How methods perform operations on object state.
- How `__repr__` and `__str__` provide readable object outputs.
- How multiple class examples can live in one module.

## How to run

From this folder, run:

```bash
python main.py
```

Expected output includes:

- arithmetic results from `Calculator`
- model training, evaluation, and prediction messages
- house information and object string representations
- car controls with acceleration and braking feedback
- teacher name access

## Notes

The code combines many simple class examples into a single module to show how Python objects can store data and behavior.
