# Day 2 - Bayes' Theorem

## Overview
This lesson focuses on Bayes' theorem, which is used to update the probability of an event based on new evidence.

## Topics Covered
- Conditional probability
- Prior probability
- Likelihood
- Posterior probability
- Real-world applications of Bayes' theorem

## Learning Objectives
By the end of this lesson, you should be able to:
- explain conditional probability
- understand the logic behind Bayes' theorem
- calculate posterior probabilities
- apply Bayes' theorem to practical decision-making examples

## Tools Used
- Python
- Jupyter Notebook
- Probability formulas

## Practice
Work through the Bayes-related examples in this folder to compute updated probabilities after seeing new evidence.
