# Day 4 - Derivatives and Gradients

## Overview
This lesson introduces the idea of derivatives, which measure how a function changes as its input changes. It also connects this idea to gradients used in optimization.

## Topics Covered
- Derivatives
- Slope and rate of change
- Gradient
- Minimizing error
- Optimization basics

## Learning Objectives
By the end of this lesson, you should be able to:
- explain what a derivative represents
- interpret slope in a function
- understand the role of gradients in machine learning
- connect derivatives to model optimization

## Tools Used
- Python
- Calculus concepts
- Jupyter Notebook

## Practice
Use the derivative exercises in this folder to practice identifying rates of change and understanding how gradients work in optimization.
