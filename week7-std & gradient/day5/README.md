# Day 5 - Chain Rule

## Overview
This lesson introduces the chain rule, a fundamental calculus concept used to differentiate complex functions built from nested functions.

## Topics Covered
- Composite functions
- Chain rule
- Multistep derivatives
- Function nesting
- Applied differentiation

## Learning Objectives
By the end of this lesson, you should be able to:
- identify composite functions
- apply the chain rule correctly
- calculate derivatives of nested expressions
- connect calculus with optimization in ML

## Tools Used
- Python
- Calculus
- Jupyter Notebook

## Practice
Work through the chain rule examples in this folder and focus on how nested functions affect differentiation.
