# Day 6 - Probability and Calculus for Machine Learning

## Overview
This lesson connects the concepts of probability and calculus to machine learning. The focus is on understanding how mathematical thinking supports model learning and decision-making.

## Topics Covered
- Probability in ML
- Calculus in optimization
- Error reduction
- Learning from data
- Statistical reasoning for models

## Learning Objectives
By the end of this lesson, you should be able to:
- explain how probability supports ML problems
- connect calculus to optimization and learning
- understand how models improve by reducing loss
- recognize the math behind ML algorithms

## Tools Used
- Python
- Jupyter Notebook
- Calculus
- Probability concepts

## Practice
Use the code and examples in this folder to connect mathematical ideas with practical ML problem solving.
