# MLflow Iris Dashboard

This project trains a small Random Forest model on the Iris dataset and logs the experiment in MLflow.

## Setup

```bash
python -m pip install -r requirements.txt
```

## Train the model

```bash
python train.py
```

## View the dashboard

```bash
streamlit run dashboard.py
```

Then open the local URL shown in the terminal, usually http://localhost:8501.
